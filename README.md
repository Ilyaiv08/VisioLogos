# VisioLogos

Программа для вывода текстов, песен и презентаций на проектор во время
церковных служений. Windows и macOS, Electron + React + TypeScript.

Главный принцип: то, что оператор делает у себя, зал не видит, пока он сам
это не отправит. Слева «Подготовка», справа «Окно слайда» — то, что прямо
сейчас на проекторе. Отправить можно кнопкой «Показать», пробелом или
двойным щелчком.

Сделана для служения, а не для показа возможностей: на служении лишняя
кнопка — это ошибка в зале.

## Что умеет

### Библия

* Модули переводов формата BibleQuote и свой формат `.vlb` — один файл
  вместо папки с сотней.
* Каталог модулей с сайта: нажали «Поставить» — скачалось и появилось
  в списке. Триста с лишним переводов, толкований и словарей.
* Четыре колонки подряд: класс, книга, глава, стих. Выделение мышью,
  `Shift+клик`, правая кнопка.
* Поиск одной строкой: «Ин 3:16» откроет стих, «в начале было слово» —
  найдёт по всей Библии.
* Два перевода на одном слайде, план мест на проповедь, подпись с адресом
  в трёх видах.
* Длинный текст режется на слайды сам — по стихам, не разрывая их
  посередине.

### Песни

* Библиотека с папками, поиск по названию, автору, номеру и любой строке
  текста.
* Импорт: текст, RTF, OpenSong, OpenLyrics (OpenLP), PowerPoint `.pptx`
  и `.ppt`, PDF, ProPresenter 4–7. Формат определяется по содержимому.
* Экспорт: текст, PowerPoint, PDF (печатный песенник), OpenSong,
  OpenLyrics.
* Куплеты, припевы, бриджи и порядок пения строкой `1-П-2-П-Б-П`.
* Припев находится по повторам: одинаковые слайды презентации сами
  становятся припевом.
* Номер задаёт место в библиотеке; порядок меняется и мышью.
* Свой фон у каждой песни — тот, что пришёл вместе с ней из презентации.
* **Каталог песен**: общий сборник общины со своими вкладками, поиском
  по всему каталогу и защитой от повторов. Вкладки переименовываются,
  добавляются и переставляются, песни носят между ними мышью.

### Тексты

Объявления, цитаты, темы проповедей, благодарности и молитвенные нужды,
обратный отсчёт и свободный слайд. Список пунктов раскладывается по слайдам
так, чтобы шрифт остался крупным. Выгрузка в текст, PDF или PowerPoint.

### Служение

План пунктов и одна кнопка «Далее» на весь ход. Пункты перетаскиваются
мышью, файлы кладутся прямо из проводника. Заметки для оператора в зал
не выводятся.

### Экраны

Зал, сцена и трансляция — каждый на своём мониторе. Сцена видит то, чего
в зале быть не должно: что идёт дальше, таймер служения, часы. Подключили
проектор — вывод сам уезжает на него, выдернули — сам возвращается окном.

Под окном слайда на «Главной» — кнопки подключённых мониторов с их
настоящим разрешением. Нажали — предпросмотр принял пропорции этого экрана
и видно, как слайд ляжет именно на нём.

### Пульт проповедника

Беспроводной презентер — для компьютера обычная клавиатура, ставить ничего
не нужно. Пульт листает то, что сейчас на экране, а не открытую вкладку,
и работает, даже когда программа свёрнута или открыто другое окно.

### Караоке

Программа слушает зал через микрофон, узнаёт слова этой самой песни
и закрашивает их за пением — по букве, а не заливая слово целиком.
Для слуха один раз ставится голосовой модуль, кнопкой или с флешки.

Цвет закраски подбирается под фон, причём для каждой строки отдельно: там,
где вверху небо, а внизу земля, верхние строки красятся тёмным, нижние —
светлым. Можно выбрать цвет и руками — палитрой из шестнадцати цветов.

### Ещё

Отмена `Ctrl+Z` по всей программе, включая поля ввода. Корзина на песни,
тексты и служения. Тринадцать стилей оформления, русский и английский язык,
снимок слайда картинкой, обновление одной кнопкой.

## Горячие клавиши

| Клавиша | Что делает |
| --- | --- |
| `F5` | Показать слайд открытой вкладки |
| `Esc` | Убрать слайд |
| `Пробел` | Дальше: по частям песни, по слайдам, по служению |
| `F12` · `B` | Чёрный экран |
| `Ctrl+F5` · `T` | Только фон, без текста |
| `K` | Караоке; `Enter` — отметить строку спетой |
| `Ctrl+Z` | Отменить последнее действие |
| `Ctrl+Shift+Z` · `Ctrl+Y` | Вернуть отменённое |
| `Page Down` `Page Up` `.` | Пульт проповедника |
| `→` `←` `↓` `↑` | Шаг по стихам, частям песни и слайдам |
| `Ctrl+1…4` | Главная, Библия, Тексты, Песни |
| `F11` | Во весь экран |
| `Ctrl+Shift+S` | Снимок слайда картинкой |
| `F1` | Подсказка по клавишам |

F-клавиши и сочетания с `Ctrl` работают и в полях ввода, остальные — нет:
оператор набирает текст спокойно.

## Установка

Готовые сборки — на [visiologos.ru](https://visiologos.ru).

Установщик ставит программу в папку пользователя, а не в `Program Files`:
тогда он не просит прав администратора, которых на приходском компьютере
обычно нет. Есть и переносная сборка одним файлом, без установки.

Песни при удалении программы остаются: библиотеку общины она за собой
не уносит.

## Сборка из исходников

```bash
npm install
npm run dev          # запуск в разработке
npm run typecheck    # проверка типов
npm run check        # самопроверка: 500 с лишним проверок чистого кода
npm run build        # сборка
npm run dist         # Windows: установщик и переносная версия
npm run dist:mac     # macOS: .dmg и .zip — только на самом маке
```

`npm run check` гоняет разбор без единого окна: раскладку текста по слайдам,
импорт и экспорт песен, порядок книг Библии, подбор цвета караоке, выбор
экрана. Ошибки в этих местах видны не сразу, а посреди служения, — поэтому
они проверяются отдельно.

## Где лежат данные

| Что | Где |
|---|---|
| Переводы Библии | `%APPDATA%/visiologos/bibles/` |
| Песни | `%APPDATA%/visiologos/songs.json` |
| Каталог песен | `%APPDATA%/visiologos/catalog.json` |
| Тексты и объявления | `%APPDATA%/visiologos/texts.json` |
| Папки служений | `%APPDATA%/visiologos/folders.json` |
| Показы и их слайды | `%APPDATA%/visiologos/decks.json`, `decks/` |
| Фоны пользователя | `%APPDATA%/visiologos/backgrounds/` |
| Голосовой модуль | `%APPDATA%/visiologos/voice/` |
| План, оформление, шаблоны | `%APPDATA%/visiologos/settings.json` |

Запись атомарная — сначала во временный файл, потом переименование: свет,
выключенный посреди сохранения, не оставит обрезанный JSON.

## Устройство

```
src/
  main/        главный процесс: библиотеки, файлы, окна вывода, PowerPoint
  preload/     мост window.api между окном и главным процессом
  renderer/    окно оператора и окно вывода: React, zustand, свои стили
  shared/      общий код обоих процессов — его и проверяет npm run check
tools/
  selfcheck.ts самопроверка
modules/       переводы Библии, которые идут в комплекте
resources/     значок программы
```

Главный процесс и окно разговаривают только через `preload`: окно не видит
ни файловой системы, ни путей. Всё, что можно проверить без окна, живёт
в `shared` — раскладка слайдов, разбор песен, порядок книг, подбор цвета.

## Чего ещё нет

* Экспорт и импорт служения одним файлом, умные папки, история версий песен.
* Отчёт по лицензии за период — данные копятся, самого отчёта нет.
* Импорт из PDF берёт только текст: сканы он прочитать не может.
* Караоке слушает только по-русски; пение на два голоса не различает.
* Клавиши пульта закреплены намертво, назначить свои нельзя.
* Пульт на телефоне, оформление для трансляции, автосохранение места
  в служении.
